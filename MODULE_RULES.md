# Правила оформления модулей

## Версионирование

- Файл `VERSION` в корне проекта содержит номер версии (semver).
- Версия **обязательно** показывается на всех страницах приложения (в navbar, `base.html`).
- Каждый коммит с изменениями в модулях должен сопровождаться увеличением версии в `VERSION`, если изменения существенны.
- Коммиты тегируются `v<номер>` в git после согласования: `git tag v1.3.0 && git push --tags`.

## Именование

- **Python**: `snake_case` для функций, переменных; `PascalCase` для классов.
- **JavaScript**: `camelCase` для функций, переменных.
- **CSS-классы**: `kebab-case` (`.tree-horizontal-wrap`, `.status-card`).
- **ID элементов**: префикс + суть (`tn_0_1`, `wt_root`).

## Python (Flask)

- Маршруты — декораторы `@app.route()`.
- Вынос логики классификации в отдельные функции (`_classify_legal`, `_classify_work`).
- Константы (цвета, статусы) — в `STATUS_REFERENCE` в ПРОПИСНЫХ.
- Импорты: стандартная библиотека → flask/sqlalchemy → локальные модули.
- Все функции с подчёркивания (`_build_tree`) — внутренние, не для внешнего вызова.

## JavaScript (шаблоны)

- Глобальные переменные (`treeLevels`) — только для состояния дерева.
- Функции рендеринга — `renderStatusTree`, `drawTreeConnectors` и т.д.
- Поиск DOM-элементов — через `document.getElementById()` (не `querySelectorAll` с индексом).
- Обработчики — `onclick`, `oninput` в HTML (inline для простоты).

## HTML-шаблоны (Jinja2)

- Наследование: `{% extends 'base.html' %}`.
- Блоки: `{% block title %}`, `{% block content %}`, `{% block scripts %}`.
- Стили — inline в атрибуте `style` (Bootstrap + кастомные).

## Git

- Ветки: `develop` — основная разработка, `main` — стабильный релиз.
- Коммиты: префикс с номером шага (`Step N: ...`) или суть изменения.
- Перед коммитом: `git status`, `git diff --stat`.

## Структура модулей

- `app.py` — маршруты, бизнес-логика, `STATUS_REFERENCE`, функции классификации.
- `models.py` — SQLAlchemy-модели, `_parse_notes_meta`.
- `templates/` — Jinja2-шаблоны.
- `static/css/style.css` — основные стили.
- `static/js/main.js` — общие JS (kanban, формы).

## UI/UX дерева статусов

- Кнопка раскрытия дочерних карточек — правая вертикальная полоса, иконка `bi-diagram-3`.
- Клик по телу карточки — фильтрация канбана по контрактам узла.
- Уровни 0–1 видны по умолчанию, 2+ скрыты.
- При раскрытии карточки её сиблинги автоматически схлопываются.
